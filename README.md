## 👋 About

Welcome to my personal portfolio repository.

This project is designed to showcase my journey as a developer — including my **skills, projects, education, experience, achievements, and technical interests**.

Rather than building a simple static resume page, I wanted the portfolio to feel like an interactive digital experience that reflects how I approach technology:

> **Explore → Build → Learn → Improve → Create Impact**

The website combines modern frontend development, animation, interactive UI, and 3D visual elements to create a distinctive portfolio experience.

🚀 Getting Started
Prerequisites

Make sure you have installed:

Node.js
pnpm
Git
Clone the repository
git clone https://github.com/Himagirisiddesh/Portfolio-Explorer-Himagiri-Siddesh-M.git
Navigate to the project
cd Portfolio-Explorer-Himagiri-Siddesh-M
Install dependencies
pnpm install
Start the development server
$env:PORT = "5173"
$env:BASE_PATH = "/"

pnpm --filter @workspace/portfolio dev

The portfolio will be available at:

http://localhost:5173
📦 Production Build

To create a production build:

pnpm --filter @workspace/portfolio build

To preview the production build:

pnpm --filter @workspace/portfolio serve
